# nddev-builder Cursor plugin

This plugin is projected into the selected Cursor configuration target as a
local native Cursor plugin under the launch-isolated home at
`.nddev-cursor-home/.cursor/plugins/local/nddev-builder`.

The plugin contains only public guidance artifacts: rules, skills, agents, and
commands. It does not declare hooks or MCP servers, does not create live server
configuration, and does not provision Cursor team marketplace state.
